ZJOOC 视频连播助手

  1. 打开并刷新 ZJOOC 课程页面。
  2. 在网页面板点击“返回课程目录”。
  3. 点击“识别全部视频”，助手会展开章节并仅收集视频。
  4. 核对视频列表，点击“开始连播”。

Windows / macOS 使用同一扩展文件夹；不需要 Python、Node.js 或脚本管理器。

视频自然结束后切换。若自动播放被浏览器阻止，请手动点播放。可在网页面板随时停止。

v1.3.1：播放中持续出现零时长约 20 秒，会保留当前队列并刷新重试，每节最多两次；可随时停止。

默认最高倍速（当前平台 4×）；可在助手面板选择 0.5×～4×，刷新后保留偏好。

课程视频默认静音，不影响其他网页和系统音量；取消勾选面板里的“课程视频默认静音”即可恢复声音。
