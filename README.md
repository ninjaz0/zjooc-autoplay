# ZJOOC 视频连播助手

面向 [ZJOOC 浙江省高校在线课程平台](https://zjooc.cn/)的 Chrome 扩展。识别课程视频、依次播放，默认使用最高倍速并静音，遇到持续零时长异常时刷新当前视频重试。

**[下载最新版安装包](https://github.com/ninjaz0/zjooc-autoplay/releases/latest) · [安装指南](INSTALL.md) · [反馈问题](https://github.com/ninjaz0/zjooc-autoplay/issues)**

Windows 和 macOS 共用同一个 ZIP。普通使用无需 Node.js、Python、编译或脚本管理器。

## 安装

1. 从 [Releases](https://github.com/ninjaz0/zjooc-autoplay/releases/latest) 下载 `zjooc-autoplay-v1.3.1.zip`，不要误下 GitHub 自动生成的 Source code。
2. 解压，得到 `zjooc-autoplay` 文件夹。
3. Chrome 地址栏输入 `chrome://extensions`，开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的 `zjooc-autoplay` 文件夹。
5. 刷新 ZJOOC 课程页面，右上方会出现助手面板。

这是未上架商店的本地扩展，不能通过双击 ZIP 完成安装。它已经包含全部运行文件，解压加载即可使用。请保留加载的文件夹，不要随意移动或删除。

已有 Tampermonkey 的用户也可以下载 Release 中的 `zjooc-autoplay.user.js`。扩展与用户脚本只启用一种。

## 使用

进入课程的“章节内容”目录页 → **识别全部视频** → 核对列表 → **开始连播**。

- **只识别视频**：自动展开章节，按视频图标和叶子节点排除模块、小节及文档。使用完整章节路径区分同名视频。
- **连续播放**：当前视频自然结束后等待 4 秒，通过平台“返回章节列表”进入下一节。
- **默认最高倍速**：当前适配播放器的档位为 0.5×、1×、1.25×、1.5×、2×、4×，默认最高 4×。可在面板选择速度；能读取菜单时优先使用菜单档位，否则使用这组已核实档位。
- **默认静音**：只将当前课程视频静音，不影响其他网页或系统音量。取消“课程视频默认静音”即可恢复声音。
- **零时长恢复**：画面实际在前进，但 `00:00 / 00:00` 或无效时长持续约 20 秒时，暂停并在 3 秒后刷新本节，不跳过视频。每节最多自动刷新两次。
- **可停止和继续**：停止会暂停视频并取消待执行的切换或刷新。面板可收起，运行状态中可以查看最近操作。

开始、切换视频和刷新恢复时，会应用已选择的倍速及静音偏好。浏览器若阻止自动播放，可手动点一次播放。保持标签页打开、电脑唤醒。

队列和设置保存在当前标签页的 `sessionStorage`，刷新后可恢复；关闭标签页或清除网站数据后可能丢失。具体视频时间点由平台播放器恢复。

## 异常恢复细节

检测结合播放器时间文字、HTML5 视频时长、实际时间或解码帧的前进情况。初始加载、暂停、拖动进度、静止缓冲不会直接触发零时长恢复，四倍速播放也不会被当作拖动进度。

重试次数跨刷新保留。达到上限后会停止，可手动检查后点击“刷新当前视频并重试”。停止或离开本节会取消待执行的刷新；不能保存队列时不会自动刷新。如果视频已结束但时间仍为零，也会重试本节，不直接进入下一节。

## 适配范围

已在一个真实课程中验证 48 节视频的识别、自动开始、从第一节切换到第二节、4× 倍速及静音播放。另有真实本地短片测试验证自然结束切换和零时长刷新恢复。**这不代表所有课程、播放器版本或整门课程的学习进度均已验证。**

只适配当前课程页面及同源 iframe 中的 HTML5 视频。跨域播放器、另开窗口、页面改版、题目或验证弹窗可能需要人工处理。

扩展不跳转视频时间，不伪造观看记录，不调用成绩或进度接口。时间显示恢复不等于服务器一定记入进度，最终以平台学习记录为准。

## 隐私与权限

扩展只在 ZJOOC 的课程路径运行，没有后台服务、外部脚本、分析统计或自建服务器，不要求账号密码。详见 [PRIVACY.md](PRIVACY.md)。

## 开发与打包

运行文件位于 `extension/`，可直接作为已解压扩展加载。以下依赖仅供开发测试，不是用户安装依赖。

```sh
npm ci
npm test
python scripts/build.py
```

测试要求 Node.js 20 或更高版本；打包使用 Python 3 标准库，不需额外 Python 包。输出位于 `dist/`：

- `zjooc-autoplay-v<版本>.zip`：可以解压加载的扩展包；
- `zjooc-autoplay.user.js`：合并后的备用用户脚本；
- `SHA256SUMS.txt`：下载校验值。

版本号以 `extension/manifest.json` 为准。GitHub Actions 在 Windows、macOS 和 Linux 上执行 DOM／事件模拟测试与打包；CI 不登录真实课程平台，也不代表三种系统均做过真实课程播放测试。
